# KleHausen-seite-remake

Ein schlichtes Onepager-Layout für das fiktive Areliaxson-Netzwerk. Die Seite ist komplett in statischem HTML, CSS und JavaScript umgesetzt.

## Projekt starten

```bash
cd /workspaces/KleHausen-seite-remake
python -m http.server 4173
```

Danach kannst du im Browser `http://localhost:4173` öffnen.
